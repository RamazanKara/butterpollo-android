# Overlay, metrics, diagnostics, crash and launcher bug hunt

Audit date: 2026-10-09. Baseline: `10ba65e8`. Android client worktree only; no host or submodule changes.
Reviewed `PARITY-MATRIX.md`, `TROUBLESHOOTING.md`, `FRONTENDS.md`, and `git log -30`, including the recent compact-overlay, latency-window, crash-capture, problem-report and frontend-export changes. The build targets API 36, compiles against API 37, and supports API 21.

## Fixed findings

Twenty findings are fixed. Severity describes the user-visible consequence, not exploitability. “Source” below means a traced framework/native path, not a claimed device reproduction. Framework tests were not added: this checkout declares JUnit and kxml2, but no Robolectric dependency. No dependencies were added.
